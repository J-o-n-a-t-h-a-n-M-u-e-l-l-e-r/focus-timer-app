# Feature: Start a focus timer from the dashboard

## Summary

Let users launch and complete a configured focus session from the dashboard.

## Acceptance criteria

- The dashboard presents a clear entry point for starting a focus session.
- Selecting the entry point opens timer setup.
- Users can select a duration and begin a visible countdown.
- The completed flow is usable with keyboard navigation.

## Dependency

Blocked by:

- Implement focus-session countdown
