# Implement focus-session countdown

## Summary

Implement the timer session behavior using the duration selected in the modal.

## Acceptance criteria

- Starting a session displays a countdown from the selected duration.
- The countdown updates once per second.
- Starting another session clears any existing countdown.
- Completion is communicated clearly to the user.

## Dependencies

Blocked by:

- Build reusable focus-timer modal shell
- Add focus-duration selection controls
